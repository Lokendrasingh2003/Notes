# 136. Single Number

## 📌 Pattern

**Bit Manipulation → XOR**

---

## 📌 Problem

We are given an array where:

* Every number appears **exactly twice**
* One number appears **only once**
* We need to find that single number

Example:

```text id="x8s8cc"
nums = [4,1,2,1,2]
```

The answer is:

```text id="3u7jha"
4
```

because:

```text id="3l7r1s"
1 → appears twice
2 → appears twice
4 → appears once
```

The problem also requires:

```text id="x7y40g"
Time  = O(n)
Space = O(1)
```

So using a `Set` or frequency object is unnecessary because that would use extra space.

---

# ⚡ Key Idea

Use **XOR (`^`)**.

The most important XOR property is:

```text id="o5l8jc"
a ^ a = 0
a ^ 0 = a
```

That means if we XOR all numbers:

```text id="ynf3q6"
4 ^ 1 ^ 2 ^ 1 ^ 2
```

the duplicate numbers cancel each other:

```text id="3c6w0f"
4 ^ (1 ^ 1) ^ (2 ^ 2)
```

Since:

```text id="l2k1cc"
1 ^ 1 = 0
2 ^ 2 = 0
```

we get:

```text id="w5j9gq"
4 ^ 0 ^ 0
= 4
```

Therefore, the number left over is the **single number**.

---

# 🧠 Your Code

```js id="8o7y7w"
var singleNumber = function(nums) {

    let result = 0

    for(let num of nums){
        result = result ^ num
    }

    return result
};
```

Your solution is **correct and optimal**.

---

# 🔍 Understanding `result`

Initially:

```js id="v5qk1b"
let result = 0
```

Then for every number:

```js id="e7q5zz"
result = result ^ num
```

So `result` keeps the XOR of all numbers processed so far.

# 🔑 The Real Magic: Duplicate Cancellation

You don't actually need to calculate every XOR manually.

Think of the entire expression:

```text id="d1yn7q"
0 ^ 4 ^ 1 ^ 2 ^ 1 ^ 2
```

Rearrange it:

```text id="7p7g8e"
0 ^ 4 ^ (1 ^ 1) ^ (2 ^ 2)
```

Now:

```text id="p6l5yx"
1 ^ 1 = 0
2 ^ 2 = 0
```

Therefore:

```text id="ydf7x0"
0 ^ 4 ^ 0 ^ 0
= 4
```

That's why XOR is perfect for this problem.

# 📌 Why Start With `0`?

You use:

```js id="r4s0p9"
let result = 0
```

because:

```text id="m8z5gd"
0 ^ x = x
```

So the first number is preserved.

For example:

```text id="a6y8q0"
0 ^ 7 = 7
```

Then we continue XORing.

# 🔍 XOR Properties to Remember

These three are especially important:

### 1. Same number cancels

```text id="7j8m9a"
x ^ x = 0
```

Example:

```text id="7u2h0p"
5 ^ 5 = 0
```

---

### 2. XOR with zero changes nothing

```text id="c4z7px"
x ^ 0 = x
```

Example:

```text id="4b6w0z"
5 ^ 0 = 5
```

---

### 3. XOR is order-independent

You can rearrange:

```text id="2x5w7r"
a ^ b ^ c
```

as:

```text id="9n8m1q"
c ^ a ^ b
```

The result is the same.

That's why all duplicate numbers can effectively cancel each other.

---

# ⚠️ Why Not Use a Set?

You could do:

```js id="2e7x3f"
let set = new Set()
```

and remove numbers when they appear twice.

But the problem specifically asks for:

```text id="g4s9wy"
O(1) extra space
```

A `Set` requires additional memory:

```text id="j6n4kx"
O(n)
```

XOR allows us to solve it with only:

```text id="s8d2qa"
result
```

so:

```text id="v3f1qz"
O(1)
```

space.

# 🎯 Interview Explanation

If the interviewer asks **"How did you solve it?"**, say:

> "I use XOR because every duplicate number cancels itself out since `x ^ x = 0`, and XOR with zero leaves the other number unchanged. I initialize `result` to zero and XOR every element with it. Since all numbers appear twice except one, all duplicates cancel and the remaining value is the single number. This gives O(n) time and O(1) extra space."

# 🧠 Memory Trick

Whenever you see:

> **Every element appears twice except one**

Think immediately:

```text id="3qj8lm"
XOR
```

Remember:

```text id="7t1p4a"
x ^ x = 0
x ^ 0 = x
```

So:

```text id="b8h2z7"
Duplicates → Cancel
Single → Remains
```

### One-line memory trick:

> **XOR everything — pairs become 0, so the single number survives.**

# 160. Intersection of Two Linked Lists

# Link : https://leetcode.com/problems/intersection-of-two-linked-lists/

## 1. Problem

Given two singly linked lists, return the **node where they intersect**.

If they never intersect, return `null`.

Example:

```text
A: 4 → 1 ─┐
          ↓
          8 → 4 → 5
          ↑
B: 5 → 6 → 1 ─┘
```

Answer:

```text
8
```

---

## 2. Pattern

**Two Pointers + Switching Heads**

Use:

```text
temp1 → headA
temp2 → headB
```

When one pointer reaches the end of its list, move it to the **head of the other list**.

```text
A → B
B → A
```

Eventually, both pointers will either meet at the intersection node or both become `null`.

---

## 3. Key Idea

The two lists may have different lengths.

For example:

```text
A: 4 → 1 → 8 → 4 → 5
B: 5 → 6 → 1 → 8 → 4 → 5
```

Pointer A has to travel:

```text
A + B
```

Pointer B travels:

```text
B + A
```

Therefore, both pointers travel the **same total number of nodes**.

This automatically removes the length difference.

The important part is:

```js
if(temp1 == null) temp1 = headB
if(temp2 == null) temp2 = headA
```

---

## 4. Approach

### Step 1: Start both pointers

```js
let temp1 = headA
let temp2 = headB
```

### Step 2: Move both one step

```js
temp1 = temp1.next
temp2 = temp2.next
```

### Step 3: When a pointer reaches `null`, switch lists

```js
if(temp1 == null) temp1 = headB
if(temp2 == null) temp2 = headA
```

So:

```text
temp1: A → B
temp2: B → A
```

### Step 4: Stop when they point to the same node

```js
while(temp1 != temp2)
```

The comparison is based on **node reference**, not node value.

---

## 5. Code

Your solution:

```js
var getIntersectionNode = function(headA, headB) {

    let temp1 = headA
    let temp2 = headB

    while(temp1 != temp2){

        temp1 = temp1.next
        temp2 = temp2.next

        if(temp1 == temp2) return temp1

        if(temp1 == null) temp1 = headB
        if(temp2 == null) temp2 = headA
    }

    return temp1
};
```

### Small simplification

The inner:

```js
if(temp1 == temp2) return temp1
```

is not necessary.

The `while` condition already checks whether they are equal.

So the cleaner version is:

```js
var getIntersectionNode = function(headA, headB) {

    let temp1 = headA
    let temp2 = headB

    while(temp1 != temp2) {

        if(temp1 == null) {
            temp1 = headB
        } else {
            temp1 = temp1.next
        }

        if(temp2 == null) {
            temp2 = headA
        } else {
            temp2 = temp2.next
        }
    }

    return temp1
};
```

Both approaches work.

## 6. Dry Run

Consider:

```text
A: 4 → 1 → 8 → 4 → 5
B: 5 → 6 → 1 → 8 → 4 → 5
```

Initially:

```text
temp1 = 4
temp2 = 5
```

After switching heads when necessary, their paths become:

```text
temp1: A → B
temp2: B → A
```

After traversing the same total distance, both reach:

```text
8
```

So:

```text
temp1 === temp2
```

and we return that node.

---

## 7. Very Important: Compare References, Not Values

This is one of the most important interview points.

Suppose:

```text
A: 4 → 1 → 8
B: 5 → 1 → 8
```

The two `1`s might have the same value but be **different nodes**.

So this is wrong:

```js
temp1.val == temp2.val
```

We need:

```js
temp1 == temp2
```

because we want to know whether both pointers refer to the **exact same node in memory**.

---

## 8. Why Switching Heads Works

Suppose:

```text
Length A = a + c
Length B = b + c
```

where `c` is the common/intersecting part.

Pointer 1 travels:

```text
A + B
```

Pointer 2 travels:

```text
B + A
```

Therefore, both travel the same total distance:

```text
a + c + b + c
```

and:

```text
b + c + a + c
```

So when an intersection exists, they meet at the first common node.

If there is no intersection, both eventually become:

```text
null
```

## 9. Complexity

### Time

```text
O(n + m)
```

Each pointer traverses both lists at most once.

### Space

```text
O(1)
```

Only two pointers are used.

## 10. Common Mistakes

### Mistake 1: Comparing values

Wrong:

```js
temp1.val == temp2.val
```

Correct:

```js
temp1 == temp2
```

### Mistake 2: Switching to the same list

Wrong:

```js
if(temp1 == null) temp1 = headA
```

It must switch to the **other** list:

```js
if(temp1 == null) temp1 = headB
```

### Mistake 3: Returning the value

The question asks for the **node**, not its value.

Correct:

```js
return temp1
```

### Mistake 4: Modifying the lists

Don't change any `next` pointers. The original structure must remain unchanged.

---

## 11. Interview Point

If asked:

**"How does switching heads solve different list lengths?"**

Answer:

> When a pointer reaches the end of its list, I move it to the head of the other list. So both pointers eventually traverse the same total number of nodes, which cancels out the difference in their lengths.

---

## 12. Memory Trick

**"A → B, B → A"**

Remember:

```text
Pointer A: headA → ... → null → headB
Pointer B: headB → ... → null → headA
```

Then:

```text
Same node → Intersection
null + null → No intersection
```

### One-line memory

> **Switch heads to cancel the length difference.**

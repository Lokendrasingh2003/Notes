# 17. Letter Combinations of a Phone Number

## 📌 Problem

Each digit from `2` to `9` maps to some letters:

```text
2 → abc
3 → def
4 → ghi
5 → jkl
6 → mno
7 → pqrs
8 → tuv
9 → wxyz
```

Given:

```text
digits = "23"
```

we need all possible combinations:

```text
[
  "ad", "ae", "af",
  "bd", "be", "bf",
  "cd", "ce", "cf"
]
```

---

## 🧠 Pattern

**Backtracking / Multiple Choices**

For every digit:

> Try every letter mapped to that digit.

For `"23"`:

```text
Digit 2
 ├── a
 ├── b
 └── c

For each of them:

Digit 3
 ├── d
 ├── e
 └── f
```

This produces:

```text
a → ad, ae, af
b → bd, be, bf
c → cd, ce, cf
```

---

# 💡 Key Idea

The most important concept is:

> **One recursion level handles one digit.**

For:

```text
digits = "23"
```

we have:

```text
index = 0 → process '2'
index = 1 → process '3'
index = 2 → all digits processed
```

So:

```js
backtrack(index + 1, current)
```

moves to the next digit.

---

# 🔍 Your Code

```js
var letterCombinations = function(digits) {

    if(digits.length === 0){
        return []
    }

    let result = []

    let map = {
        "2": "abc",
        "3": "def",
        "4": "ghi",
        "5": "jkl",
        "6": "mno",
        "7": "pqrs",
        "8": "tuv",
        "9": "wxyz"
    }

    function backtrack(index, current){

        if(index == digits.length){
            result.push(current)
            return
        }

        let letters = map[digits[index]]

        for(let letter of letters){

            current += letter

            backtrack(index + 1, current)

            current = current.slice(0, -1)
        }
    }

    backtrack(0, "")

    return result
};
```

Your logic is correct. ✅

# 🌳 Recursion Tree

The recursion looks like this:

```text
                       ""
              /         |         \
             a          b          c
           / | \      / | \      / | \
          ad ae af   bd be bf   cd ce cf
```

When we reach:

```text
index === digits.length
```

we have created one complete combination.

For example:

```text
"ad"
```

So:

```js
result.push(current)
```

stores it.

---

# ⭐ Understanding `current += letter`

This line:

```js
current += letter
```

adds the current letter.

Example:

```text
current = ""
letter = "a"

current = "a"
```

Then we process the next digit.

Suppose the next letter is `"d"`:

```text
current = "a"
letter = "d"

current = "ad"
```

Now `"ad"` is a complete combination.

---

# 🔙 Why Do We Remove the Last Letter?

This line is extremely important:

```js
current = current.slice(0, -1)
```

It is the **backtracking step**.

Suppose we have:

```text
current = "ad"
```

After storing `"ad"`, we need to try:

```text
"ae"
```

So we remove the last character:

```text
"ad"
 ↓ remove d
"a"
```

Then add:

```text
e
```

giving:

```text
"ae"
```

So the pattern is:

```text
Add
↓
Recurse
↓
Remove
```

### Memory trick:

> **Choose → Explore → Undo**

# 🛑 Base Case

Your base case:

```js
if(index == digits.length){
    result.push(current)
    return
}
```

means:

> We have processed every digit, so `current` is now a complete answer.

For `"23"`:

```text
index = 0 → digit 2
index = 1 → digit 3
index = 2 → finished
```

Therefore:

```text
index === digits.length
```

is the correct stopping condition.

---

# ❓ Why Do We Increment `index`?

This:

```js
backtrack(index + 1, current)
```

means:

> Move to the next digit.

For example:

```text
digits = "234"
```

The recursion processes:

```text
index 0 → 2
index 1 → 3
index 2 → 4
index 3 → finished
```

So **each recursion level corresponds to one digit**.

This is one of the most important things to remember.

# 🔥 Difference From Previous Backtracking Problems

This problem is slightly different from the subset/combination problems you've just done.

### Subsets II

You were choosing elements from an array:

```js
backtracking(i + 1, current)
```

### Combination Sum

You were choosing numbers based on a target.

### Letter Combinations

You have a **string of digits**, and every digit provides a set of choices:

```text
digit → letters → choose one
```

So the structure is:

```text
Digit
 ↓
Get its letters
 ↓
Try each letter
 ↓
Move to next digit
```

---

# ⚠️ Important Difference: `current +=` vs `push/pop`

Here you use:

```js
current += letter
```

and undo using:

```js
current = current.slice(0, -1)
```

This works because strings are immutable in JavaScript.

You could also use an array:

```js
current.push(letter)

backtrack(index + 1, current)

current.pop()
```

and at the base case:

```js
result.push(current.join(""))
```

Both approaches work.

Your string approach is perfectly valid.

# ⏱️ Complexity

Each digit has at most 4 letters.

For `n` digits, the maximum number of combinations is:

```text
4^n
```

For each combination, we build a string of length `n`.

Therefore:

```text
Time: O(n × 4^n)
```

Auxiliary recursion/path space:

```text
O(n)
```

Output space:

```text
O(n × 4^n)
```

because there can be `4^n` strings, each of length `n`.

Since the problem has:

```text
n <= 4
```

the search space is small.

# 🗣️ Interview Explanation

> "I use backtracking where each recursion level represents one digit. I maintain a mapping from each digit to its possible letters. For the current digit, I iterate through all its letters, add one letter to the current string, recursively process the next digit, and then remove the last letter to backtrack. When the index reaches the length of the digits string, I have a complete combination, so I add it to the result."

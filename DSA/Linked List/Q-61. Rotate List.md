# 61. Rotate List

## Link : https://leetcode.com/problems/rotate-list/

## 📌 Problem

Given the `head` of a linked list, rotate the list to the **right by `k` places**.

### Example

```text
Input:  1 → 2 → 3 → 4 → 5, k = 2
Output: 4 → 5 → 1 → 2 → 3
```

---

## 🧠 Pattern

**Linked List + Length + Circular Connection**

---

## 💡 Key Idea

Instead of actually moving nodes one by one:

1. Find the **length** of the list and the `tail`.
2. Reduce unnecessary rotations using:

   ```js
   k % length
   ```
3. Find the node at position:

   ```text
   length - (k % length)
   ```
4. Connect `tail` to `head` to make the list circular.
5. The node after the new tail becomes the new `head`.
6. Break the circular connection.

### Memory Trick

> **Find Length → Find Break Point → Make Circular → Break**

---

## 🔍 Approach

For:

```text
1 → 2 → 3 → 4 → 5
k = 2
```

Length:

```text
5
```

Effective rotation:

```text
k % length = 2
```

We need to break the list after:

```text
length - k = 5 - 2 = 3
```

So:

```text
1 → 2 → 3 | 4 → 5
```

Make it circular:

```text
1 → 2 → 3 → 4 → 5
↑               ↓
└───────────────┘
```

Then:

* `temp = 3` → new tail
* `temp.next = 4` → new head
* `tail.next = null` → break the circle

Result:

```text
4 → 5 → 1 → 2 → 3
```

---

## 💻 Code

```js
var rotateRight = function(head, k) {

    if (!head || !head.next || k === 0) return head;

    let tail = head;
    let length = 1;

    // Find length and tail
    while (tail.next != null) {
        length++;
        tail = tail.next;
    }

    // No rotation needed
    if (k % length === 0) return head;

    // Find the new tail
    let rotate = length - (k % length);

    let temp = head;

    for (let i = 1; i < rotate; i++) {
        temp = temp.next;
    }

    // Make list circular
    tail.next = head;

    // New head is after new tail
    head = temp.next;

    // Break the circle
    temp.next = null;

    return head;
};
```

---

## 🔎 Important Lines

### 1. Reduce large `k`

```js
if (k % length === 0) return head;
```

If:

```text
length = 3
k = 4
```

Then:

```text
4 % 3 = 1
```

Rotating 4 times is the same as rotating once.

---

### 2. Find the new tail

```js
let rotate = length - (k % length);
```

For:

```text
1 2 3 4 5
k = 2
```

```text
rotate = 5 - 2 = 3
```

So `temp` reaches node `3`.

```text
1 → 2 → 3 → 4 → 5
          ↑
        temp
```

Node `3` becomes the **new tail**.

---

### 3. Make the list circular

```js
tail.next = head;
```

Before:

```text
1 → 2 → 3 → 4 → 5 → null
```

After:

```text
1 → 2 → 3 → 4 → 5
↑               ↓
└───────────────┘
```

This allows the last nodes to move to the front without physically moving each node.

---

### 4. Set the new head

```js
head = temp.next;
```

Since `temp` is node `3`:

```text
3 → 4
```

Therefore:

```text
head = 4
```

---

### 5. Break the circular list

```js
temp.next = null;
```

This changes:

```text
1 → 2 → 3 → 4 → 5 → 1 ...
          ↑
       new tail
```

into:

```text
4 → 5 → 1 → 2 → 3 → null
```

---

## 🧪 Dry Run

### Input

```text
head = 1 → 2 → 3 → 4 → 5
k = 2
```

### Step 1: Find length

```text
length = 5
tail = 5
```

### Step 2: Effective rotation

```text
k % length
= 2 % 5
= 2
```

### Step 3: Find new tail

```text
rotate = 5 - 2
       = 3
```

Move `temp` 2 times:

```text
temp = 1
temp = 2
temp = 3
```

### Step 4: Make circular

```text
5.next = 1
```

### Step 5: New head

```text
head = 3.next
     = 4
```

### Step 6: Break

```text
3.next = null
```

### Final

```text
4 → 5 → 1 → 2 → 3
```

## ⏱️ Complexity

### Time

```text
O(n)
```

We traverse the list to find its length and then traverse again to find the break point.

### Space

```text
O(1)
```

Only a few pointers are used.

---

## ⚠️ Common Mistakes

### 1. Forgetting `k % length`

`k` can be as large as:

```text
2 × 10⁹
```

So always reduce it:

```js
k % length
```

### 2. Breaking at the wrong node

For right rotation:

```text
new tail = length - (k % length)
```

### 3. Forgetting to break the circular list

After:

```js
tail.next = head;
```

you **must** do:

```js
temp.next = null;
```

Otherwise, the list contains a cycle.

### 4. Forgetting edge cases

```js
if (!head || !head.next || k === 0) return head;
```

Handles:

* Empty list
* One-node list
* `k = 0`

## 🎯 Interview Point

If the interviewer asks:

**"Can you do it without moving each node individually?"**

Say:

> "Yes. I'll first find the length and tail, reduce `k` using `k % length`, connect the tail to the head to form a circular list, then find the new tail and break the circle at that point."

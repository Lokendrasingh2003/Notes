# What is AI?

#### Simple Definition

**Artificial Intelligence (AI)** is a field of computer science that enables machines to perform tasks that normally require **human intelligence**, such as:

- Understanding language
- Recognizing images
- Learning from data
- Making decisions
- Solving problems
- Generating text, images, or code

In simple words:

> **AI is the technology that enables computers to learn, reason, and perform intelligent tasks instead of following only explicitly programmed instructions.**

---

### Traditional Programming vs AI

**Traditional Programming:**

```
Input + Rules → Output
```

Example:


if marks >= 40:
    return "Pass"
else:
    return "Fail"


The developer explicitly defines the rules.

**AI / Machine Learning:**

```
Data + Learning Algorithm → Model → Prediction / Decision
```

The system learns patterns from data and uses those patterns to make predictions or decisions.

---

### Types of AI

For interview purposes, you should know these:

#### 1. Narrow AI / Weak AI

AI designed to perform a **specific task**.

Examples:

- ChatGPT
- Face recognition
- Recommendation systems
- Spam detection
- Voice assistants

Most AI systems we use today are **Narrow AI**.

---

#### 2. General AI / AGI

AI that could perform a wide range of intellectual tasks at a **human-like level**.

AGI does not currently exist as a generally accepted real-world technology.

---

#### 3. Super AI

A hypothetical AI that would surpass human intelligence across virtually all domains.

Super AI does not currently exist and remains a theoretical concept.

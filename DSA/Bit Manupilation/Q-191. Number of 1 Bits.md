# 191. Number of 1 Bits

## 📌 Pattern

**Bit Manipulation → Check Last Bit → Right Shift**

The problem asks us to count how many `1`s are present in the binary representation of `n`.

This is also called the **Hamming Weight**.

---

# 📌 Problem

Given a positive integer `n`, return the number of `1` bits in its binary representation.

Example:

```text
n = 11
```

Binary:

```text
11 = 1011
```

There are three `1`s:

```text
1 0 1 1
↑   ↑ ↑
```

Answer:

```text
3
```

---

# ⚡ Key Idea

We can check the **last bit** of `n` using:

```js
n & 1
```

Then remove the last bit using:

```js
n >> 1
```

So the process is:

```text
Check last bit
      ↓
If it is 1 → count++
      ↓
Right shift
      ↓
Repeat
```

---

# 🧠 Your Code

```js
var hammingWeight = function(n) {

    let count = 0

    while(n > 0){

        if(n & 1){
            count++
        }

        n = n >> 1
    }

    return count
};
```

Your solution is **correct**.

---

# 🔍 Understanding `n & 1`

This is the most important part.

Suppose:

```text
n = 11
```

Binary:

```text
1011
```

We want to check the last bit:

```text
1011
   ↑
   1
```

We use:

```js
n & 1
```

Binary:

```text
1011
0001
----
0001
```

The result is `1`, so:

```js
count++
```

If the last bit were `0`:

```text
1010
0001
----
0000
```

then:

```js
n & 1
```

would give `0`.

Therefore:

```text
n & 1 === 1
        ↓
Last bit is 1

n & 1 === 0
        ↓
Last bit is 0
```

---

# 🔄 Understanding `n >> 1`

After checking the last bit, we need to move to the next bit.

For example:

```text
1011
```

Right shift by one:

```text
1011 >> 1
```

gives:

```text
0101
```

The last bit has effectively been removed.

So:

```text
1011
 ↓
0101
 ↓
0010
 ↓
0001
 ↓
0000
```

We check one bit on every iteration.

# 🔑 What Is Happening Conceptually?

Your algorithm is basically:

```text
1011
 ↑
Check 1 → count

0101
 ↑
Check 1 → count

0010
 ↑
Check 0

0001
 ↑
Check 1 → count
```

So:

```text
1 + 1 + 0 + 1 = 3
```

# 🚀 Follow-Up: Can We Optimize It?

The problem asks:

> If this function is called many times, how would you optimize it?

There is a better technique called **Brian Kernighan's Algorithm**.

Instead of checking **every bit**, it directly removes the rightmost `1` bit.

The trick is:

```js
n = n & (n - 1)
```

---

# 🔥 Why Does `n & (n - 1)` Remove One `1`?

Consider:

```text
n = 12
```

Binary:

```text
1100
```

Now:

```text
n - 1 = 1011
```

AND them:

```text
  1100
& 1011
------
  1000
```

The rightmost `1` has disappeared:

```text
1100
 ↓
1000
```

So every time we execute:

```js
n = n & (n - 1)
```

we remove exactly **one set bit**.

---

# 🚀 Optimized Solution

```js
var hammingWeight = function(n) {

    let count = 0

    while(n !== 0){

        n = n & (n - 1)
        count++
    }

    return count
};
```

If a number contains only a few `1`s, this can be faster because we only loop once per set bit.

# 🆚 Your Approach vs Optimized Approach

### Your approach

```js
while(n > 0){
    if(n & 1){
        count++
    }
    n = n >> 1
}
```

It checks every bit.

```text
Time: O(log n)
Space: O(1)
```

### Brian Kernighan's approach

```js
while(n !== 0){
    n = n & (n - 1)
    count++
}
```

It processes only the `1` bits.

```text
Time: O(k)
Space: O(1)
```

where `k` = number of set bits.

So if:

```text
n = 10000000000000000000000000000001
```

there are only **2 set bits**, and Kernighan's algorithm needs only 2 iterations instead of checking all 32 bits.

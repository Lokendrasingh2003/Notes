# 138. Copy List with Random Pointer

## Link : https://leetcode.com/problems/copy-list-with-random-pointer/

## 📌 Problem

Given a linked list where every node has:

* `val`
* `next`
* `random`

The `random` pointer can point to **any node in the list** or `null`.

Create a **deep copy** containing completely new nodes.

### Example

```text
Original:

7 → 13 → 11 → 10 → 1

Random:
7.random  → null
13.random → 7
11.random → 1
10.random → 11
1.random  → 7
```

The copied list must have the same structure, but **none of its pointers should point to original nodes**.

---

## 🧠 Pattern

**Linked List + Deep Copy + Interleaving Nodes**

---

## 💡 Key Idea

Normally, we could use a `HashMap`:

```text
original node → copied node
```

But your solution avoids extra space by putting every copied node **between its original node and its next node**.

For example:

```text
Original:

A → B → C
```

After inserting copies:

```text
A → A' → B → B' → C → C'
```

Now if:

```text
A.random → C
```

then:

```text
A'.random → C'
```

And `C'` is simply:

```js
A.random.next
```

because every original node is immediately followed by its copy.

---

# 🔄 Three-Step Approach

Your solution has exactly **3 phases**:

```text
1. Insert copied nodes
2. Connect random pointers
3. Separate original and copied lists
```

### Memory Trick

> **Insert → Random → Separate**

---

# 1️⃣ Insert Copy Nodes

Your function:

```js
function insertNodeBetween(head){

    let temp = head

    while(temp){
        let copy = new _Node(temp.val)

        copy.next = temp.next
        temp.next = copy

        temp = temp.next.next
    }
}
```

Suppose the original list is:

```text
1 → 2 → 3
```

After this function:

```text
1 → 1' → 2 → 2' → 3 → 3'
```

### Important part

```js
copy.next = temp.next
temp.next = copy
```

First:

```text
temp → next
```

becomes:

```text
temp → copy → next
```

Then:

```js
temp = temp.next.next
```

moves from:

```text
1
```

to:

```text
2
```

because `temp.next` is the copy.

---

# 2️⃣ Connect Random Pointers

Your function:

```js
function connectRandomNode(head){

    let temp = head

    while(temp){

        let copy = temp.next

        if(temp.random){
            copy.random = temp.random.next
        }
        else{
            copy.random = null
        }

        temp = temp.next.next
    }
}
```

This is the **most important trick** in the problem.

Because the structure is:

```text
Original → Copy
```

If:

```text
temp.random
```

points to an original node, then:

```text
temp.random.next
```

points to its copy.

### Example

```text
A → A' → B → B' → C → C'
```

If:

```text
A.random → C
```

then:

```js
A.random.next
```

is:

```text
C'
```

So:

```js
copy.random = temp.random.next
```

correctly connects:

```text
A'.random → C'
```

### Why not `temp.random`?

Because that would make the copied node point back to an **original node**, which violates the deep-copy requirement.

---

# 3️⃣ Separate the Two Lists

Your function:

```js
function makeNewList(head){

    let dummy = new _Node(-1)
    let res = dummy
    let temp = head

    while(temp){

        res.next = temp.next

        temp.next = temp.next.next

        res = res.next
        temp = temp.next
    }

    return dummy.next
}
```

At this point:

```text
Original → Copy → Original → Copy
```

For example:

```text
1 → 1' → 2 → 2' → 3 → 3'
```

We need:

```text
Original:
1 → 2 → 3
```

and:

```text
Copy:
1' → 2' → 3'
```

### Important lines

```js
res.next = temp.next
```

Take the copied node and add it to the new list.

Then:

```js
temp.next = temp.next.next
```

Restore the original list by skipping the copied node.

---

# 🧪 Dry Run

Consider:

```text
A → B → C
```

with:

```text
A.random → C
B.random → A
C.random → null
```

### Phase 1 — Insert

```text
A → A' → B → B' → C → C'
```

### Phase 2 — Random

For `A`:

```text
A.random = C
C.next = C'
```

Therefore:

```text
A'.random = C'
```

For `B`:

```text
B.random = A
A.next = A'
```

Therefore:

```text
B'.random = A'
```

For `C`:

```text
C.random = null
```

Therefore:

```text
C'.random = null
```

### Phase 3 — Separate

Final original:

```text
A → B → C
```

Final copied list:

```text
A' → B' → C'
```

with:

```text
A'.random → C'
B'.random → A'
C'.random → null
```

# 💻 Complete Code

```js
var copyRandomList = function(head) {

    insertNodeBetween(head)

    connectRandomNode(head)

    let newHead = makeNewList(head)

    return newHead
};

function insertNodeBetween(head){

    let temp = head

    while(temp){
        let copy = new _Node(temp.val)

        copy.next = temp.next
        temp.next = copy

        temp = temp.next.next
    }
}

function connectRandomNode(head){

    let temp = head

    while(temp){

        let copy = temp.next

        if(temp.random){
            copy.random = temp.random.next
        }
        else{
            copy.random = null
        }

        temp = temp.next.next
    }
}

function makeNewList(head){

    let dummy = new _Node(-1)
    let res = dummy
    let temp = head

    while(temp){

        res.next = temp.next

        temp.next = temp.next.next

        res = res.next
        temp = temp.next
    }

    return dummy.next
}
```

---

## ⚠️ Important Edge Case

If:

```text
head = null
```

your functions handle it naturally because all `while(temp)` loops are skipped.

`dummy.next` remains `null`, so the answer is `null`.

---

## ⚠️ Common Mistakes

### 1. Using `temp.random` directly

Wrong:

```js
copy.random = temp.random
```

This makes the copied node point to an **original node**.

Correct:

```js
copy.random = temp.random.next
```

---

### 2. Forgetting `temp.random === null`

Always handle:

```js
if(temp.random)
```

otherwise accessing:

```js
temp.random.next
```

would cause an error.

---

### 3. Losing the original `next`

When inserting:

```js
copy.next = temp.next
temp.next = copy
```

The original next node must first be assigned to `copy.next`.

---

### 4. Not restoring the original list

After creating the copy, the original list should be restored.

```js
temp.next = temp.next.next
```

---

## ⏱️ Complexity

Let `n` be the number of nodes.

### Time

```text
O(n)
```

We traverse the list three times:

```text
Insert → O(n)
Random → O(n)
Separate → O(n)
```

Overall:

```text
O(3n) = O(n)
```

### Extra Space

```text
O(1)
```

No `HashMap` or array is used.

The copied nodes themselves require `O(n)` memory, but that is **output space**, not auxiliary space.

---

## 🎯 Interview Point

There are **two standard approaches**.

### Approach 1 — HashMap

```text
Original node → Copy node
```

* Time: `O(n)`
* Extra space: `O(n)`
* Easier to understand

### Approach 2 — Interleaving Nodes

```text
Original → Copy → Original → Copy
```

* Time: `O(n)`
* Extra space: `O(1)`
* More clever and optimal

Your solution uses **Approach 2**.

Remember the entire solution as:

```text
INSERT → RANDOM → SEPARATE
```

Or:

> **Put copy beside original → use `.random.next` → split the lists**

### Most Important Line

```js
copy.random = temp.random.next
```

Why?

> Because every original node is immediately followed by its copied node.

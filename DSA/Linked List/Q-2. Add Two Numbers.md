# 2. Add Two Numbers

## Link : https://leetcode.com/problems/add-two-numbers/

## 1. Problem

Two linked lists represent two numbers.

The digits are stored in **reverse order**, so the first node contains the units digit.

Example:

```text
l1 = 2 → 4 → 3
l2 = 5 → 6 → 4
```

They represent:

```text
342 + 465 = 807
```

So the result is:

```text
7 → 0 → 8
```

---

## 2. Pattern

**Two Pointers + Carry + Dummy Node**

We traverse both linked lists together and perform normal digit-by-digit addition.

```text
digit1 + digit2 + carry
```

Then:

```text
digit = sum % 10
carry = floor(sum / 10)
```

---

## 3. Key Idea

Because the digits are already reversed:

```text
2 → 4 → 3
↑
units digit
```

we can start adding immediately.

For every position:

```text
sum = l1 digit + l2 digit + carry
```

For example:

```text
2 + 5 + 0 = 7
```

Next:

```text
4 + 6 + 0 = 10
```

So:

```text
digit = 0
carry = 1
```

Next:

```text
3 + 4 + 1 = 8
```

Result:

```text
7 → 0 → 8
```

---

## 4. Approach

### Step 1: Create a dummy node

```js
let dummy = new ListNode(0)
let temp = dummy
```

The dummy node makes it easy to build the result list without separately handling the first node.

### Step 2: Start with carry `0`

```js
let carry = 0
```

Initially there is no carry.

### Step 3: Traverse while there is something to process

```js
while(temp1 || temp2 || carry)
```

This condition is important because:

* `temp1` may still have digits
* `temp2` may still have digits
* `carry` may remain after both lists end

### Step 4: Add available digits

```js
let sum = carry

if(temp1){
    sum += temp1.val
    temp1 = temp1.next
}

if(temp2){
    sum += temp2.val
    temp2 = temp2.next
}
```

If one list is shorter, its missing digit is simply treated as `0`.

### Step 5: Calculate digit and carry

```js
carry = Math.floor(sum / 10)
let digit = sum % 10
```

For example:

```text
sum = 17

digit = 17 % 10 = 7
carry = floor(17 / 10) = 1
```

### Step 6: Add the digit to the result

```js
temp.next = new ListNode(digit)
temp = temp.next
```

Finally:

```js
return dummy.next
```

---

## 5. Code

```js
var addTwoNumbers = function(l1, l2) {

    let temp1 = l1
    let temp2 = l2

    let dummy = new ListNode(0)
    let temp = dummy

    let carry = 0

    while(temp1 || temp2 || carry) {

        let sum = carry

        if(temp1) {
            sum += temp1.val
            temp1 = temp1.next
        }

        if(temp2) {
            sum += temp2.val
            temp2 = temp2.next
        }

        carry = Math.floor(sum / 10)

        let digit = sum % 10

        temp.next = new ListNode(digit)
        temp = temp.next
    }

    return dummy.next
};
```

## 6. Dry Run

Input:

```text
l1 = 2 → 4 → 3
l2 = 5 → 6 → 4
```

| Step | l1 | l2 | Carry | Sum | Digit | New Carry |
| ---- | -: | -: | ----: | --: | ----: | --------: |
| 1    |  2 |  5 |     0 |   7 |     7 |         0 |
| 2    |  4 |  6 |     0 |  10 |     0 |         1 |
| 3    |  3 |  4 |     1 |   8 |     8 |         0 |

Result:

```text
7 → 0 → 8
```

Which represents:

```text
807
```

---

## 7. Important Case: Different Lengths

Suppose:

```text
l1 = 9 → 9 → 9
l2 = 1
```

After `l2` becomes `null`, we continue processing `l1`.

The missing `l2` digit contributes `0`.

So the algorithm naturally handles:

```text
999 + 1 = 1000
```

Result:

```text
0 → 0 → 0 → 1
```

No separate loop is required.

---

## 8. Important Case: Final Carry

Consider:

```text
l1 = 9
l2 = 9
```

First:

```text
9 + 9 + 0 = 18
```

Therefore:

```text
digit = 8
carry = 1
```

Now both lists are finished, but:

```text
carry = 1
```

The loop condition:

```js
while(temp1 || temp2 || carry)
```

is still true.

So another node is created:

```text
8 → 1
```

Correct answer:

```text
8 → 1
```

representing `18`.

---

## 9. Why `while(temp1 || temp2 || carry)`?

This is one of the most important lines.

If we used only:

```js
while(temp1 || temp2)
```

we could lose a final carry.

For example:

```text
9 + 9 = 18
```

After processing both nodes:

```text
carry = 1
```

Therefore, `carry` must also be part of the loop condition.

---

## 10. Why Use a Dummy Node?

Without a dummy node, we would need special logic for creating the first result node.

With:

```js
let dummy = new ListNode(0)
let temp = dummy
```

we can always do:

```js
temp.next = new ListNode(digit)
temp = temp.next
```

At the end:

```js
return dummy.next
```

gives the actual result.

---

## 11. Complexity

Let:

```text
n = length of l1
m = length of l2
```

### Time

```text
O(max(n, m))
```

We process each digit once.

### Space

```text
O(max(n, m))
```

The result linked list contains the sum's digits.

Apart from the output list, the algorithm uses:

```text
O(1)
```

auxiliary space.

## 12. Common Mistakes

### Mistake 1: Forgetting the carry

Always include:

```js
let sum = carry
```

before adding the digits.

### Mistake 2: Using `/ 10` directly for carry

In JavaScript:

```js
carry = sum / 10
```

can produce a decimal.

Use:

```js
carry = Math.floor(sum / 10)
```

### Mistake 3: Forgetting the final carry

Use:

```js
while(temp1 || temp2 || carry)
```

instead of only checking the two lists.

### Mistake 4: Reversing the lists unnecessarily

The problem already stores digits in reverse order:

```text
2 → 4 → 3
```

represents `342`.

So we can directly add from the head.

### Mistake 5: Returning the dummy node

Return:

```js
return dummy.next
```

not:

```js
return dummy
```

---

## 13. Interview Point

If asked:

**"Why don't you reverse the linked lists?"**

Answer:

> The digits are already stored in reverse order, so the least significant digits are at the heads of the lists. I can therefore perform the addition directly while traversing forward and propagate the carry.

---

## 14. Memory Trick

### **Add → Digit → Carry → Move**

For every node:

```text
sum = digit1 + digit2 + carry
```

Then:

```text
digit = sum % 10
carry = floor(sum / 10)
```

And move both pointers forward.

### One-line memory:

> **Two lists + carry → calculate digit → attach result → move forward.**

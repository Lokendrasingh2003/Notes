# 25. Reverse Nodes in k-Group

## Link : https://leetcode.com/problems/reverse-nodes-in-k-group/

## 1. Problem

Given a linked list, reverse its nodes **k at a time**.

If the final group contains fewer than `k` nodes, leave that group unchanged.

Example:

```text
Input:  1 → 2 → 3 → 4 → 5
k = 2

Output: 2 → 1 → 4 → 3 → 5
```

For:

```text
Input: 1 → 2 → 3 → 4 → 5
k = 3
```

Output:

```text
3 → 2 → 1 → 4 → 5
```

---

## 2. Pattern

**Linked List Reversal + Group Processing**

For every group:

```text
Find kth node
     ↓
Save next group
     ↓
Disconnect current group
     ↓
Reverse current group
     ↓
Connect reversed group
     ↓
Move to next group
```

### Memory Trick

> **Find K → Save Next → Cut → Reverse → Connect → Repeat**

---

## 3. Key Idea

Suppose:

```text
1 → 2 → 3 → 4 → 5
k = 3
```

First find the 3rd node:

```text
1 → 2 → 3
        ↑
      kthNode
```

Save the next group:

```js
let nextNode = kthNode.next
```

So:

```text
Current group: 1 → 2 → 3
Next group:             4 → 5
```

Disconnect:

```js
kthNode.next = null
```

Now reverse:

```text
3 → 2 → 1
```

Finally connect:

```text
3 → 2 → 1 → 4 → 5
```

---

## 4. Approach

### Step 1: Find the kth node

Your helper:

```js
function findknode(temp, k){
    while(temp && k > 1){
        k--
        temp = temp.next
    }

    return temp
}
```

If there are at least `k` nodes, it returns the kth node.

If fewer than `k` nodes remain, it returns `null`.

---

### Step 2: Save the next group

Before breaking the current group:

```js
nextNode = kthNode.next
```

This is important because after:

```js
kthNode.next = null
```

we would otherwise lose the connection to the remaining list.

---

### Step 3: Disconnect the current group

```js
kthNode.next = null
```

Now only the current `k` nodes are connected.

Example:

```text
1 → 2 → 3    4 → 5
```

---

### Step 4: Reverse the group

```js
reverse(temp)
```

The group becomes:

```text
3 → 2 → 1
```

The important detail is that `temp` was originally the first node:

```text
temp = 1
```

After reversal, `temp` becomes the **last node** of the reversed group.

So:

```text
temp = 1
```

is useful as the tail when connecting the next group.

---

### Step 5: Update the head

For the first group:

```js
if(temp == head){
    head = kthNode
}
```

Before reversal:

```text
head → 1 → 2 → 3
```

After reversal:

```text
head → 3 → 2 → 1
```

Therefore, `kthNode` becomes the new head.

---

### Step 6: Connect previous group

For subsequent groups:

```js
previousNode.next = kthNode
```

Example:

```text
Previous group
3 → 2 → 1
          ↓
        previousNode
```

Next reversed group:

```text
6 → 5 → 4
```

Connect:

```text
3 → 2 → 1 → 6 → 5 → 4
```

---

### Step 7: Move to the next group

```js
previousNode = temp
temp = nextNode
```

Here `temp` is the tail of the group we just reversed.

---

## 5. Code

Your approach:

```js
var reverseKGroup = function(head, k) {

    let temp = head

    let previousNode = new ListNode(null)
    let nextNode = new ListNode(null)

    while(temp){

        let kthNode = findknode(temp, k)

        if(kthNode == null){
            if(previousNode){
                previousNode.next = temp
                break
            }
        }

        nextNode = kthNode.next
        kthNode.next = null

        reverse(temp)

        if(temp == head){
            head = kthNode
        }
        else{
            previousNode.next = kthNode
        }

        previousNode = temp
        temp = nextNode
    }

    return head
};

function findknode(temp, k){

    while(temp && k > 1){
        k--
        temp = temp.next
    }

    return temp
}

function reverse(temp){

    let prev = null
    let current = temp

    while(current){

        let next = current.next
        current.next = prev
        prev = current
        current = next
    }

    return prev
}
```

### Cleaner version

You don't need to create `ListNode` objects for `previousNode` and `nextNode`.

```js
var reverseKGroup = function(head, k) {

    let temp = head
    let previousNode = null

    while(temp){

        let kthNode = findKNode(temp, k)

        // Fewer than k nodes remain
        if(kthNode == null){
            if(previousNode){
                previousNode.next = temp
            }
            break
        }

        let nextNode = kthNode.next

        // Disconnect current group
        kthNode.next = null

        // Reverse current group
        reverse(temp)

        // First group becomes the new head
        if(temp == head){
            head = kthNode
        }
        else{
            previousNode.next = kthNode
        }

        // temp is now the tail of the reversed group
        previousNode = temp

        // Move to next group
        temp = nextNode
    }

    return head
};

function findKNode(temp, k){

    while(temp && k > 1){
        k--
        temp = temp.next
    }

    return temp
}

function reverse(head){

    let prev = null
    let current = head

    while(current){

        let next = current.next
        current.next = prev
        prev = current
        current = next
    }

    return prev
}
```

## 6. Dry Run

Input:

```text
1 → 2 → 3 → 4 → 5
k = 2
```

### Group 1

Find kth node:

```text
1 → 2
    ↑
   kth
```

Save:

```text
nextNode = 3
```

Reverse:

```text
2 → 1
```

`2` becomes the new head.

Current result:

```text
2 → 1
```

---

### Group 2

Start at:

```text
3 → 4 → 5
```

Find kth node:

```text
3 → 4
    ↑
   kth
```

Save:

```text
nextNode = 5
```

Reverse:

```text
4 → 3
```

Connect after the previous group's tail:

```text
2 → 1 → 4 → 3
```

---

### Remaining nodes

Only:

```text
5
```

remain.

Since there are fewer than `k = 2` nodes, leave them unchanged:

```text
2 → 1 → 4 → 3 → 5
```

---

## 7. Why Save `nextNode` Before Reversing?

This is one of the most important parts.

Before reversing:

```text
1 → 2 → 3 → 4 → 5
```

For the first group:

```text
1 → 2
```

we save:

```js
let nextNode = kthNode.next
```

so:

```text
nextNode = 3
```

Then we disconnect:

```js
kthNode.next = null
```

Without saving `3`, the connection to the remaining list would be lost.

So remember:

> **Save the next group before breaking the current group.**

---

## 8. Why Is `temp` the Previous Tail?

Initially:

```text
temp → 1 → 2
```

After reversing:

```text
2 → 1
```

The original `temp` is still node `1`.

Therefore:

```text
temp = 1
```

and `1` is now the **tail** of the reversed group.

That's why:

```js
previousNode = temp
```

works.

For the next group:

```text
2 → 1 → 4 → 3
      ↑
 previousNode
```

---

## 9. Why Don't We Reverse the Last Incomplete Group?

Suppose:

```text
1 → 2 → 3 → 4 → 5
k = 3
```

First group:

```text
1 → 2 → 3
```

can be reversed.

Remaining:

```text
4 → 5
```

Only 2 nodes remain, which is less than `k`.

So:

```text
3 → 2 → 1 → 4 → 5
```

The condition:

```js
if(kthNode == null)
```

detects this situation.

---

## 10. Important Pointer Relationships

For every complete group:

```text
previousNode → current group → nextNode
```

Before reversal:

```text
previousNode → 1 → 2 → 3 → nextNode
```

After disconnecting:

```text
previousNode    1 → 2 → 3    nextNode
```

After reversing:

```text
previousNode    3 → 2 → 1    nextNode
```

Then reconnect:

```text
previousNode → 3 → 2 → 1 → nextNode
```

This is the entire problem.

---

## 11. Complexity

Let `n` be the number of nodes.

### Time

```text
O(n)
```

Each node is visited while finding groups and reversing them.

Although `findKNode()` and `reverse()` are called multiple times, each operation processes only the relevant portion of the list, giving overall linear time.

### Space

```text
O(1)
```

Only pointers are used.

This satisfies the follow-up asking for **constant extra memory**.

---

## 12. Common Mistakes

### Mistake 1: Forgetting to save the next group

Wrong order:

```js
kthNode.next = null
let nextNode = kthNode.next
```

Now `nextNode` is `null`.

Correct:

```js
let nextNode = kthNode.next
kthNode.next = null
```

---

### Mistake 2: Reversing fewer than `k` nodes

Always check:

```js
if(kthNode == null)
```

before reversing.

---

### Mistake 3: Losing the new head

After reversing the first group:

```text
1 → 2 → 3
```

becomes:

```text
3 → 2 → 1
```

So the head must become:

```js
head = kthNode
```

---

### Mistake 4: Connecting the wrong node

After reversing a group, the original first node becomes its tail.

Therefore:

```js
previousNode = temp
```

not:

```js
previousNode = kthNode
```

---

### Mistake 5: Creating unnecessary ListNodes

These:

```js
new ListNode(null)
```

are unnecessary because `previousNode` and `nextNode` are only pointers.

Use:

```js
let previousNode = null
let nextNode = null
```

---

## 13. Interview Point

If asked:

**"What makes this problem difficult?"**

Answer:

> The main challenge is maintaining the connections between groups while reversing each group in-place. For every group, I first find the kth node, save the next group's head, disconnect the current group, reverse it, connect it with the previous group, and then continue.

If asked about the follow-up:

> I don't use recursion or any extra data structure. I only use a constant number of pointers, so the auxiliary space is O(1).

## 14. Memory Trick

### **F → S → C → R → C → M**

```text
F = Find Kth node
S = Save next group
C = Cut current group
R = Reverse group
C = Connect groups
M = Move to next group
```

Think:

```text
Find K
  ↓
Save Next
  ↓
Cut
  ↓
Reverse
  ↓
Connect
  ↓
Repeat
```

**One-line memory:**

> **Find K → Save Next → Cut → Reverse → Connect → Repeat**

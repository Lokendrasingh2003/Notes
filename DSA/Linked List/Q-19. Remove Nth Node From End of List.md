# 19. Remove Nth Node From End of List

### Pattern

**Two Pointer + Dummy Node**

### Problem

Given the head of a linked list, remove the `nth` node from the **end** of the list.

Example:

```text id="n2e7r8"
Input:
1 → 2 → 3 → 4 → 5

n = 2
```

The 2nd node from the end is:

```text id="u4t6t9"
4
```

After removing it:

```text id="p8f2kd"
1 → 2 → 3 → 5
```

---

# Key Idea

We use two pointers:

```text id="j0y0h6"
slow
fast
```

First, move `fast` **n steps ahead**.

Then move both `slow` and `fast` together until `fast` reaches the end.

Because `fast` started `n` nodes ahead, `slow` will reach the node **just before the node we want to delete**.

Then:

```javascript id="f9v2j7"
slow.next = slow.next.next;
```

deletes the target node.

---

# Why Do We Need a Dummy Node?

We create:

```javascript id="6x3v5a"
let dummy = new ListNode(0);
dummy.next = head;
```

So the list becomes:

```text id="j7n6px"
dummy → 1 → 2 → 3 → 4 → 5
```

This makes deleting the **first node** much easier.

For example:

```text id="5xq3w0"
1 → 2 → 3
n = 3
```

The node to remove is `1`.

Without a dummy node, we need a special case.

With a dummy:

```text id="q5f4qa"
dummy → 1 → 2 → 3
```

`slow` can simply point to `dummy`, and:

```javascript id="c0s9eg"
slow.next = slow.next.next;
```

removes `1`.

---

# Step 1: Create Dummy Node

```javascript id="x4x1av"
let dummy = new ListNode(0);
dummy.next = head;
```

Now:

```text id="j2x1z8"
dummy → 1 → 2 → 3 → 4 → 5
```

Initialize:

```javascript id="7h6g5e"
let slow = dummy;
let fast = dummy;
```

---

# Step 2: Move Fast `n` Steps

```javascript id="4x1h7c"
for (let i = 0; i < n; i++) {
    fast = fast.next;
}
```

For:

```text id="x4k4x8"
1 → 2 → 3 → 4 → 5
n = 2
```

After moving `fast` twice:

```text id="q4x9n1"
dummy → 1 → 2 → 3 → 4 → 5
             ↑
            fast
```

`slow` is still at `dummy`.

---

# Step 3: Move Both Pointers

Now:

```javascript id="h8s3q0"
while (fast.next != null) {
    slow = slow.next;
    fast = fast.next;
}
```

We continue until `fast` reaches the last node.

Eventually:

```text id="b8w0n5"
dummy → 1 → 2 → 3 → 4 → 5
                  ↑       ↑
                slow     fast
```

Notice:

```text id="r6f1x2"
slow.next = 4
```

So `slow` is exactly **one node before the node we want to delete**.

---

# Step 4: Delete the Node

Now:

```javascript id="n9r5p1"
slow.next = slow.next.next;
```

Before:

```text id="m2q6v0"
3 → 4 → 5
    ↑
   delete
```

After:

```text id="z7k4p3"
3 → 5
```

Final result:

```text id="s4w2x8"
1 → 2 → 3 → 5
```

---

# Code

```javascript id="k8m3q2"
var removeNthFromEnd = function(head, n) {

    // Dummy node handles the case
    // where the head itself needs to be removed.
    let dummy = new ListNode(0);
    dummy.next = head;

    let slow = dummy;
    let fast = dummy;

    // Move fast n steps ahead
    for (let i = 0; i < n; i++) {
        fast = fast.next;
    }

    // Move both until fast reaches the last node
    while (fast.next != null) {
        slow = slow.next;
        fast = fast.next;
    }

    // Delete nth node from the end
    slow.next = slow.next.next;

    return dummy.next;
};
```

# Dry Run

Let's use the important example:

```text id="5k9b1q"
head = [1,2,3,4,5]
n = 2
```

Initial:

```text id="n3g4q7"
dummy → 1 → 2 → 3 → 4 → 5
  ↑
slow
fast
```

### Move `fast` 2 steps

First:

```text id="x3y6c1"
dummy → 1 → 2 → 3 → 4 → 5
  ↑         ↑
slow       fast
```

Second:

```text id="c7w8n2"
dummy → 1 → 2 → 3 → 4 → 5
  ↑              ↑
slow            fast
```

Now:

```text id="m5j8k3"
slow = dummy
fast = 2
```

---

### Move both pointers

Iteration 1:

```text id="g1d4v9"
slow = 1
fast = 3
```

Iteration 2:

```text id="h5s8q2"
slow = 2
fast = 4
```

Iteration 3:

```text id="k2m6x7"
slow = 3
fast = 5
```

Now:

```javascript id="v5r2n8"
fast.next == null
```

Loop stops.

Therefore:

```text id="j4q7p1"
slow = 3
slow.next = 4
```

Node `4` is the node we need to remove.

---

### Delete

```javascript id="b9t3k6"
slow.next = slow.next.next;
```

Becomes:

```text id="a3f7x9"
3 → 5
```

Final:

```text id="w5k1p8"
1 → 2 → 3 → 5
```

---

# Important Concept: The Gap

This is the main thing to remember.

After moving `fast` `n` steps ahead:

```text id="h2j8q4"
slow
 ↓
1 → 2 → 3 → 4 → 5
              ↑
             fast
```

The gap between them allows `slow` to find the `nth` node from the end.

### Memory Trick

> **Move fast `n` steps → move both → slow stops before target → delete `slow.next`.**

---

# Why `while (fast.next != null)`?

This is very important.

We want `slow` to stop **before** the node that needs to be deleted.

So we stop when:

```text id="f3v6j2"
fast = last node
```

not when:

```text id="q1m7x5"
fast = null
```

Therefore:

```javascript id="c6n2p8"
while (fast.next != null)
```

is used.

---

# Edge Case: Remove the Head

Consider:

```text id="z8k3m1"
1 → 2 → 3
n = 3
```

We need to delete `1`.

With the dummy node:

```text id="a7v2c5"
dummy → 1 → 2 → 3
```

After moving `fast` 3 steps:

```text id="q4m9x6"
slow = dummy
fast = 3
```

The loop doesn't run.

Then:

```javascript id="t6p2r8"
slow.next = slow.next.next;
```

becomes:

```text id="d5k1w9"
dummy → 2 → 3
```

Finally:

```javascript id="n7x3c4"
return dummy.next;
```

returns:

```text id="b4q8m2"
2 → 3
```

This is why the **dummy node is so useful**.

# Complexity

### Time: `O(n)`

We traverse the list once.

```text id="r4v7n2"
O(n)
```

### Space: `O(1)`

Only a few pointers are used:

```text id="k8f3m6"
dummy
slow
fast
```

```text id="w2p5x9"
O(1)
```

---

# Important Interview Point

This problem is not about finding the length first.

A common approach is:

```text id="e5x8m1"
1. Find length
2. Calculate target position
3. Traverse again
4. Delete
```

That works, but requires **two passes**.

The optimal approach uses the two-pointer technique to solve it in **one pass**.

---

# Pattern to Remember

```text id="p8m2k5"
Dummy Node
    ↓
slow = dummy
fast = dummy
    ↓
Move fast n steps
    ↓
Move slow + fast together
    ↓
slow = node before target
    ↓
slow.next = slow.next.next
    ↓
return dummy.next
```

### One-Line Memory Trick

> **Fast ahead by N → move together → delete `slow.next`.**

---

# Common Mistakes

### ❌ Mistake 1: Moving `fast` `n + 1` times

Your implementation uses:

```javascript id="s3k7m2"
for (let i = 0; i < n; i++)
```

That's correct for the way you're using:

```javascript id="x8p4q6"
while (fast.next != null)
```

Don't randomly change the number of steps without changing the loop logic.

---

### ❌ Mistake 2: Returning `head`

Because the head itself might be deleted.

Use:

```javascript id="v7m3n9"
return dummy.next;
```

---

### ❌ Mistake 3: Forgetting the dummy node

Without a dummy node, deleting the first node requires a separate condition.

The dummy node makes all deletion cases follow the same logic.
